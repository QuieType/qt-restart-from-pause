# Restart from Pause
Adds a 'Restart Game' button to the pause menu. This is mostly for people testing mods that affect the game's js code, where to test changes the game must be restarted. Of course, many of those modders -- unlike myself -- already have established workflows for ding so, but maybe someone else will find use for this too.

Credit to Krypek and ADudeCalledLeo for code I used as a reference (ie. blatently copied), which allowed me to put this mod together in some spare minutes.
